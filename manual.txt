Мануал модерації магазину ZX-KIT
Цей документ описує процес додавання нових товарів та компонентів на сайт, а також оновлення пошукової карти (sitemap).

1. Додавання товарів (Основний каталог)
Щоб новий товар з'явився у загальному каталозі та на сторінці товару, необхідно виконати два кроки:

Додавання даних товару:

Відкрийте файл /data/products.json.

Додайте новий об'єкт товару в масив згідно зі структурою існуючих товарів. Переконайтеся, що id унікальний.

Оновлення індексу каталогу:

Відкрийте файл /data/catalog.json.

Додайте посилання на товар (або його короткі дані), щоб він відображався у списку товарів на головній сторінці.

2. Додавання компонентів
Додавання компонентів реалізовано простіше:

Відкрийте файл /data/components.json.

Додайте об'єкт компонента в масив.

Важливо: Оскільки система динамічно генерує сторінки компонентів, додавання лише в data/components.json достатньо для того, щоб товар з'явився у відповідному розділі.

3. Робота з медіафайлами
Завантажте необхідні зображення у папку /img/.

У файлах .json (в полях img або images) вказуйте коректний відносний шлях до файлу (наприклад, /img/new-product.jpg).

4. Оновлення SEO (Sitemap)
Після того, як ви додали новий товар або компонент, необхідно оновити карту сайту, щоб пошукові системи швидше проіндексували зміни.

Переконайтеся, що у вас встановлено Python.

У кореневій папці сайту запустіть скрипт:

Bash
python python_sitemap.py
Скрипт автоматично просканує дані та оновить файл sitemap.xml.

Чек-лист модератора:
[ ] Зображення завантажено в /img/.

[ ] Дані додані в products.json та catalog.json (для товарів) або components.json (для компонентів).

[ ] id товару унікальний.

[ ] Запущено python_sitemap.py для оновлення посилань.

[ ] Перевірено відображення на сайті після очищення кешу браузера (якщо потрібно).
